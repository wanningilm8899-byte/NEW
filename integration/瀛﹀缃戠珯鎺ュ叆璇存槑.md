# Water Risk Copilot 与原 GitHub Pages 网站接入说明

原展示站：
https://wanningilm8899-byte.github.io/water-risk-mvp/index.html

## 当前建议：先独立运行，再做链接接入

现有展示站是静态 GitHub Pages，而 Water Risk Copilot 需要 Python 后端执行数据校验、Baseline、Scenario 和日志，因此不能只把 `.py` 文件复制进 GitHub Pages 就运行。

最稳妥的接法是：

1. 保留原展示站作为研究介绍 / 地图 / 结果展示入口；
2. 将本 Agent 部署为一个独立地址；
3. 在原网站导航栏或首页增加 “AI 智能助手” 按钮，跳转到 Agent。

### 学姐网站中可直接加入的按钮

```html
<a class="ai-agent-entry" href="https://YOUR-AGENT-DOMAIN/" target="_blank">
  AI 智能助手
</a>
```

样式：

```css
.ai-agent-entry {
  display:inline-flex;
  align-items:center;
  padding:10px 16px;
  border-radius:10px;
  background:#0d6f8b;
  color:#fff;
  text-decoration:none;
  font-weight:700;
}
```

## 如果以后拿到学姐网站源码，可直接把 Agent 前端合并进去

本项目 `static/` 已经故意做成“前后端可分离”结构：

- `index.html`
- `styles.css`
- `app.js`
- `config.js`

只需把这四个文件复制到学姐仓库的一个目录，例如：

```text
water-risk-mvp/
  index.html
  ...
  agent/
    index.html
    styles.css
    app.js
    config.js
```

然后把 `agent/config.js` 的：

```js
apiBase: ""
```

改成部署后的 Python 后端地址：

```js
apiBase: "https://YOUR-AGENT-API-DOMAIN"
```

再在原网站添加：

```html
<a href="agent/index.html">AI 智能助手</a>
```

这样视觉页面可以放在同一个 GitHub Pages 仓库，但计算仍由后端执行。

## 等拿到学姐源码后需要继续做的事

1. 复用她现有的导航栏、字体、配色和卡片样式；
2. 保留她已经做好的数据展示页面；
3. 把本 Agent 作为 “智能决策助手 / Water Risk Copilot” 新页面加入；
4. 统一企业 / 材料选择状态（如有）；
5. 将她页面里写死的核心结果逐步替换为本 API 返回值；
6. 做跨页面链接和演示路径。
